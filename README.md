# Local Player

端末内の MP3 ファイルを再生するブラウザ用プレイヤーです。iPhone（Safari）を優先していますが、Android（Chrome）でも動きます。

**公開 URL：https://ey10n.github.io/LocalPlayer/**

## 機能

- 端末内の MP3 を選んでライブラリに追加（複数まとめて選択可）。追加した曲はブラウザ内（IndexedDB）に保存されるので、次回からは選び直す必要がありません
- ID3 タグからタイトル・アーティスト・アルバム・ジャケット画像を読み取り（Shift_JIS の古いタグにも対応）
- プレイリストの作成・名前変更・削除。曲の追加（ファイルから／ライブラリから）、並べ替え、プレイリストからの削除
- シャッフル、リピート（オフ／全曲／1曲）
- 画面ロック中やバックグラウンドでも再生を継続し、曲が終わると次の曲へ進みます
- ロック画面・通知に曲名とジャケットを表示し、そこから再生／一時停止・前後の曲・シークを操作可能（Media Session API）
- 再生中のリスト・曲・再生位置を保存し、次に開いたときに続きから再生

## 配置方法

静的ファイルだけで動くため、ビルドは不要です。ディレクトリ一式を **HTTPS** の Web サーバー（GitHub Pages、Netlify、社内サーバーなど）に置いてください。

- `index.html` をファイルとして直接開く（`file://`）と、ES モジュールが読み込めないため動きません
- HTTP でも再生はできますが、オフライン起動（Service Worker）は HTTPS でしか有効になりません

PC から LAN 内で試すだけなら、次のコマンドでサーバーを起動し、iPhone から `http://<PCのIPアドレス>:8000/` を開いてください。

```sh
python3 -m http.server 8000
```

## iPhone での使い方

1. Safari でページを開く
2. 共有ボタン →「ホーム画面に追加」（推奨。理由は下記）
3. 「＋ MP3を追加」→「ブラウズ」から「ファイル」アプリ内の MP3 を選択（iCloud Drive、このiPhone内、外部ストレージなど）
4. 曲をタップして再生。そのまま画面をロックしても再生が続きます

## 注意事項・制限

- **保存データの消去**：iOS の Safari では、ホーム画面に追加していないサイトのデータは、7 日間開かないと削除されることがあります。ホーム画面に追加して使うことを推奨します。アプリ側でも永続保存（`navigator.storage.persist()`）を要求しています
- **保存容量**：MP3 はブラウザの保存領域にコピーされるため、端末の空き容量を消費します。使用量はメニュー（右上の ⋯）で確認できます
- **ミュージックアプリの曲は再生できません**：iOS の「ミュージック」ライブラリ（Apple Music を含む）の曲はブラウザから読み出せません。「ファイル」アプリにある MP3 が対象です
- **音量**：iOS ではブラウザから音量を変更できない仕様のため、音量は本体のボタンで調整してください
- **同じファイルの再追加**：ファイル名とサイズが同じ曲は重複して保存せず、既存の曲を使います
- 他のアプリが音声を再生したときや着信時は一時停止します（OS の仕様）。ロック画面の再生ボタンで再開できます

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `style.css` | スタイル（ライト／ダーク対応） |
| `js/app.js` | 再生制御・プレイリスト・画面描画・Media Session |
| `js/db.js` | IndexedDB への保存 |
| `js/id3.js` | ID3v2 タグの読み取り |
| `sw.js` | オフライン起動用 Service Worker |
| `manifest.webmanifest`, `icons/` | ホーム画面追加用 |

アプリ本体を更新したときは、`sw.js` の `CACHE` の値（`local-player-v3`）を変更すると、利用者の端末で新しい版に切り替わります。

## 動作の仕組み（バックグラウンド再生）

- 再生には `<audio>` 要素を 1 つだけ使います。Web Audio API はロック時に止まるため使用していません
- iOS は「ユーザー操作の直後」以外の `play()` を拒否することがあるため、起動時に全曲の再生用 URL を用意しておき、曲の切り替えを待ち時間なく同期的に行っています。これにより、ロック中に曲が終わっても次の曲へ途切れず進みます
- 1 曲リピートは `audio.loop` で処理しています
